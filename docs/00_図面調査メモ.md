## 3. 図面から「読める」こと

- 各棟の外形寸法と、室の並び・寸法（1/600平面図に寸法記入あり）
- 各棟の配置と向き（1/1600配置図。寸法の記入はないため、縮尺から読み取る＝誤差±1m程度）
- 2階の渡り廊下が2本（②: ①⇔⑤、52: ㊸⇔⑤）
- 階段の位置（平面図に階段記号あり）
- 方位記号（配置図左下。45度刻みの概略表示）

## 4. 図面から「読めない」こと（現地確認が必要）

| 項目 | 影響 |
|---|---|
| **各棟の出入口の位置** | 屋外経路の終点が決まらない。最重要 |
| 屋外の通路（どこを歩けるか・通行禁止エリア） | 経路グラフの屋外部分 |
| 1階レベルでの棟同士の接続（屋根付き通路など） | 配置図の「吹（吹き抜けの渡廊下）」記号の扱い |
| 室の扉の位置 | 部屋の「入口」座標。当面は室の中心で代用可 |
| 正確な方位 | 図面の方位記号は概略。**旧ARmapで実測した planUpBearing=303.3度** が使える見込み |
| ページ1とページ2（㊷・体育館周辺）の相対位置 | ㊷電子科実習棟への経路 |
| 室名の現状（図面は施設台帳上の名称。実際の呼び名・用途変更） | 検索で見つからない |
